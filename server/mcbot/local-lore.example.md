# Local lore

Anything in this file is appended to the system prompt. Use it for the
landmarks, conventions and history specific to your world — the bot has no
other way to know them. Copy to `local-lore.md` (gitignored) and edit.

Example:

The hub is a floating island called Star City. It reads as an enclosed cave
from inside. A prominent warp pad goes to the main base; smaller pads around
the edges have signs naming their destinations.
